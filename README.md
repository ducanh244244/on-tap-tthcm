# Ôn Tập Tư Tưởng Hồ Chí Minh (220 Câu Trắc Nghiệm)

Trang web tĩnh (HTML/CSS/JS thuần) để ôn tập 220 câu hỏi trắc nghiệm môn Tư tưởng Hồ Chí Minh trên cả máy tính và điện thoại.

## Tính năng chính
- Đủ **220/220 câu** kèm lọc theo Chương (`1+2`, `3+4`, `5`, `6`).
- Chia thành **7 bộ chuyên đề** (Ngày tháng năm & Giai đoạn, Con số, Đại hội & Sự kiện, Tác phẩm của Bác, Cặp dễ nhầm & Giải nghĩa, Lý thuyết Chương 1–4, Lý thuyết Chương 5–6).
- **4 chế độ học**: Luyện tập chấm điểm ngay, Thẻ nhớ (Flashcard), Tra cứu & Tìm kiếm, Bảng mẹo nhớ nhanh.
- **Làm lại câu sai**, đánh dấu sao câu khó, đảo câu/đảo đáp án, lưu tiến độ tự động trên trình duyệt (`localStorage`).

## Cách đưa lên GitHub Pages để học trên điện thoại
1. Tạo một repository mới trên GitHub (ví dụ `on-tap-tthcm`, để **Public**).
2. Chạy các lệnh sau trong Terminal tại thư mục này:
   ```powershell
   git remote add origin https://github.com/<ten-github-cua-ban>/on-tap-tthcm.git
   git push -u origin main
   ```
3. Vào repository trên GitHub → **Settings** → **Pages** → ở mục **Build and deployment / Branch**, chọn **`main`** và **`/ (root)`** → bấm **Save**.
4. Đợi ~1 phút để GitHub tạo link `https://<ten-github-cua-ban>.github.io/on-tap-tthcm/` rồi mở link đó trên điện thoại để ôn tập mọi lúc!
